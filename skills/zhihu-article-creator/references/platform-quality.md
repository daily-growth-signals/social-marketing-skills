# Zhihu quality gates

Checks after evidence-based drafting. Not a viral template library.

## Reader expectations

- Direct title: judgment or unique angle (zh-CN often ~15–30 characters)  
- Early conclusion from **this** analysis  
- Clear sections when long; each section can open with its own conclusion  
- Platform claims tied to retrieved sources  
- Low hard-sell; no shock titles  

## Fact clarity (always)

- Degree words → numbers/facts from evidence or user; else `【待填】`  
- Keep “可能 / 通常” when coverage is partial  
- One meaning, one term inside one draft  
- Cut empty courtesy and filler in factual sentences  

## Allowed vs forbidden craft

| Allowed | Forbidden as system default |
| --- | --- |
| Contrast or longer paragraphs when they carry real argument | Empty slogan pairs with no mechanism |
| User-supplied firsthand story as evidence | Invented “从业十年” authority |
| Structure unique to this sample’s gaps | Shared three-genre / hook menus for every topic |

## Self-check

- [ ] Judgment cites retrieved items; inferences labeled  
- [ ] Outline would change if the sample changed  
- [ ] No unread-full-answer claims  
- [ ] `【待填】` on personal/unverifiable gaps  
- [ ] Sources + limitations present  
- [ ] Not an ad, not a fingerprint template
