# Xiaohongshu quality gates

Not a carousel template pack. Not a full technical-Chinese ban on spoken tone.

## Always on (honesty)

- No fake 实测 / 前后对比 / 价格 without user input → `【待填】`  
- No cloning other notes verbatim  
- No “全网都在…” from a small SignalDig page  
- Cut empty AI filler and fake urgency that adds no fact  
- Sources and limitations present  

## Platform voice (do not over-correct)

- 你/我、场景、口语节奏 OK  
- Topic-specific hooks OK; shared hook banks not OK  
- Do not flatten every note into a dry manual  
- Do not force Zhihu-style long authority intros without user material  

## Self-check

- [ ] Angle justified by this retrieval; sample size stated  
- [ ] Outline tied to this sample’s gaps (not a fixed N-page script)  
- [ ] Image brief (if any) does not claim files exist  
- [ ] Would be hard to mass-reproduce by only swapping the topic noun
